StoreApp is an integrated system composed of Items , Customers and Orders and a structured application where I focused on building a scalable, multi-layer architecture and applying practical software engineering concepts, including:

🔹 Core & OOP: C#, Object-Oriented Principles, Generic Programming

🔹 Architecture & Design: N-Layer Architecture (BL, DataAccessLayer, Domains, Utilities)

🔹 Data Access: Generic Repository Pattern

🔹 Core Concepts: Domain Models & Validation, Custom Exceptions, File Handling

🔹 Advanced C# Features: Reflection & Async/Await Programming
